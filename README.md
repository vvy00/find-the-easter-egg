# Find the Easter Egg 🐣

This game allows you to search for the hidden easter egg. The easter eggs are hidden behind items that spawn at different places. There are 1-3 levels to go through. If you beat level 3 your win the game. Built with HTML, CSS, and JavaScript.

## Level 1
- This level has 2 items
- Find the easter egg

## Level 2
- This level has 4 items (includes the moving bunny)
- Find the easter egg

## Level 3
- This level has 8 items (includes the moving bunny)
- This level is played in the dark (flashlight is enabled to help search for the easter egg)
- Find the easter egg
